Getting Started with GitHub

Everything you need before starting your first project.

Create a GitHub account at github.com/signup if you don't already have one.

Once your account is ready, share your GitHub username or email address with the CTSDMC GitHub administrator to receive an invitation to the UI-CTSDMC GitHub organization and access to the appropriate project repositories.

There are several ways to work with GitHub, including directly through the GitHub website, using command-line tools, or integrating GitHub with development environments and desktop applications.

For this guide, we will focus on GitHub Desktop, a user-friendly application that provides a visual interface for managing repositories, branches, and changes without requiring command-line experience.
