GitHub Desktop

Install, sign in, learn the key terms, and explore the interface.

Install GitHub Desktop

Download and install GitHub Desktop from the official GitHub Desktop website . If GitHub Desktop is available in your organization's Software Center, you can install it from there instead.

Sign In

Open GitHub Desktop and select Sign in to GitHub.com. Follow the prompts in your browser to authorize GitHub Desktop, then return to the application.

GitHub Desktop welcome and sign-in screen

Once you are signed in, GitHub Desktop is ready to connect to repositories you have permission to access.

Before working with a project, it helps to understand a few common Git and GitHub terms.

Term What it means
Repository A project folder that Git tracks, including its files and change history.
Clone Create a local copy of an existing repository on your computer.
Branch A separate line of development that allows changes without directly modifying another branch.
Commit Save a recorded snapshot of changes in your local repository.
Push Send your local commits to the remote repository on GitHub.
Fetch Check for and download remote updates without merging them into your current branch.
Pull Bring remote updates into your local branch.
Pull Request A request to review proposed changes before merging them into another branch.
Merge Combine changes from one branch into another.
Origin The usual name for the remote repository associated with your local clone.
Main The default primary branch in many repositories.

The GitHub Desktop interface provides quick access to your repository, branches, changes, and commit history. The screenshot below shows the main workspace.

GitHub Desktop main interface — click the image to enlarge
Current Repository Shows which local repository you are currently working in. Use it to switch repositories.
Current Branch Shows your active branch. Use it to switch between or create branches.
Fetch Origin Checks for new updates from the remote repository. Depending on the status, this area may show Pull or Push.
Changes Displays local file changes that have not yet been committed.
History Shows previous commits and the recorded changes in the selected branch's history.
Summary A short, required message describing the changes included in your commit.
Description An optional space to provide additional details about your commit.
Commit to Branch Records your selected changes locally on the current branch. The button displays the active branch name.
